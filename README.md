# AI, explained without the hype

A one-page, beginner-friendly website explaining artificial intelligence, its benefits, risks and possible future. This project was created for a university web assignment and is designed to work on GitHub Pages.

## Files

- `index.html` contains the page structure and written content.
- `styles.css` controls the colours, layout, type and mobile design.

The website intentionally uses no JavaScript or external libraries. This keeps it fast, simple to understand and easy to maintain.

## View the site locally

Double-click `index.html` to open it in a browser. No installation is required.

## Publishing

1. Create a public GitHub repository named `ai-project`.
2. Upload `index.html`, `styles.css` and this `README.md` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait a few minutes and open the GitHub Pages address shown by GitHub.
